# Selenium WebDriver with Java - Learning Journey 🚀

This repository documents my hands-on learning experience with **Selenium WebDriver using Java**. It includes a wide range of topics essential for web automation testing, along with practical examples and test case implementations.

## 🧠 Topics Covered

### ✅ Locators & Selectors
- ID, Name, ClassName, TagName, LinkText, PartialLinkText
- XPath (absolute & relative)
- CSS Selectors

### 🔄 WebDriver Methods
- Navigating pages (get, navigate.to, back, forward, refresh)
- Managing timeouts
- Handling browser windows and tabs

### 🧩 Handling Web Elements
- Checkboxes
- Radio buttons
- Alerts and popups (JavaScript alerts)
- IFrames (switching between frames)
- Dropdowns (Select class)
- Tables (extracting data, dynamic rows/columns)
- Date pickers
- Mouse actions (hover, drag & drop, double click, right click)

### 📸 Extra Utilities
- Taking screenshots
- Uploading files

### 🧪 Test Case Development
- Writing and organizing test cases using:
  - Selenium WebDriver
  - Java
